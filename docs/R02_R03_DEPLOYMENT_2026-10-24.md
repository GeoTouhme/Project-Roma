## Rollback

Prepared emergency rollback, restoring only the two preceding service images and preserving the same IPs/ports/mounts/environment:

```bash
sudo bash /root/roma-r02-r03-20261024T143739Z/rollback.sh
```

The script accepts `customer-panel` or `backend` to target one service; default is both. It uses `--no-deps --no-build --pull never --force-recreate` and never removes volumes or unrelated containers. It also restores the service `latest` aliases to the saved images. No database restore is required for this additive code/schema change.

**Reverting the backend reopens R02/R03.** Prefer a reviewed forward fix unless critical availability requires rollback. New JWTs and fragment reset links are incompatible with the old backend; sessions cannot be promised across rollback. The recovered customer image remains available if the original missing image ID cannot be restored.
